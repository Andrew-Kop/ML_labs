## Описание проекта

Проект решает задачу **классификации**: предсказать, будет ли пациент с диабетом повторно госпитализирован, на основе данных о 130 больницах США за 1999–2008 гг. Задача важна с практической точки зрения — понимание риска повторной госпитализации позволяет скорректировать лечение и снизить нагрузку на систему здравоохранения.

Целевая переменная `readmitted` имеет три класса:
- `NO` — повторной госпитализации не было;
- `<30` — повторная госпитализация менее чем через 30 дней (плохой знак, возможно, лечение было подобрано неверно);
- `>30` — повторная госпитализация более чем через 30 дней.

**Датасет:** [diabetic_data.csv](https://raw.githubusercontent.com/Andrew-Kop/ML_labs/main/diabetic_data.csv) — записи о госпитализациях пациентов с диабетом.

## Что делает ноутбук `ML_HW_1`

1. **Загрузка данных** — чтение CSV, обзор размерности датасета.
2. **Отбор признаков** — удаление идентификаторов и признаков с большим числом пропусков/уникальных значений (`encounter_id`, `patient_nbr`, `weight`, `payer_code`, `diag_1..3` и др.).
3. **Разбиение на train/test** (85/15).
4. **Визуализация и EDA:**
   - гистограммы числовых признаков (время в больнице, число процедур, лекарств и т.д.);
   - попарные scatter-графики числовых признаков;
   - boxplot'ы для выявления выбросов;
   - корреляционная матрица (метод Спирмена) с интерпретацией связей между признаками.
5. **Обработка пропусков** — заполнение категориальных признаков модой.
6. **Кодирование категориальных данных** — `LabelEncoder` для бинарных признаков (`gender`, `change`, `diabetesMed`), ручной маппинг возрастных групп (`age`) в числа.
7. **Нормализация** числовых признаков через `StandardScaler` (важно для KNN, работающего на расстояниях).
8. **Обучение классификаторов:**
   - **KNN** — подбор оптимального `k` в диапазоне 2–50 по точности на train/test;
   - **Логистическая регрессия**;
   - **Дерево решений**.
9. **Оценка качества** — accuracy, матрица ошибок (confusion matrix), classification report, сравнение времени обучения моделей.
10. **Анализ дисбаланса классов** в целевой переменной.

**Итог:** логистическая регрессия и KNN показали схожую точность (~57%), дерево решений — хуже (~46%). Общая точность признана невысокой — классам сложно разграничиться по имеющимся признакам.

## Что добавляет ноутбук `ML_HW_7`

Ноутбук полностью включает в себя пайплайн из HW1 (тот же EDA, предобработка, классификация) и расширяет его блоком **кластеризации без учителя**:

1. Берётся 40% данных (полный объём был слишком тяжёлым для вычислений) и проводится более полная предобработка: заполнение пропусков (мода/медиана), маппинг возраста и дозировок препаратов, one-hot encoding категориальных признаков (`race`, `admission_type_id`, `admission_source_id`), масштабирование числовых признаков.
2. **PCA** до 2 компонент — для визуализации кластеров на плоскости.
3. **KMeans** — подбор оптимального числа кластеров `k` по silhouette score (перебор `k=2..10`).
4. **DBSCAN** — подбор параметра `eps` через метод ближайших соседей (k-distance graph, квантиль 0.90).
5. **Gaussian Mixture Model (GMM)** — подбор числа компонент по критерию BIC.
6. **Оценка качества кластеризации:** silhouette score, ARI, NMI, homogeneity/completeness/v-measure (сравнение с истинными метками `readmitted`).
7. **Визуализация** результатов всех трёх методов в пространстве главных компонент (PCA), таблица сопряжённости кластеров и истинных классов.

**Итог:** качество кластеризации получилось низким — лучший результат у KMeans при k=2 (silhouette ≈ 0.14), GMM показал отрицательный silhouette, DBSCAN — очень низкое качество с заметной долей точек-шума. Это говорит о том, что естественной кластерной структуры, совпадающей с целевой переменной, в данных не прослеживается.

## Используемые библиотеки и навыки (skills)

**Работа с данными**
- `pandas`, `numpy` — загрузка, очистка и трансформация табличных данных

**Визуализация**
- `matplotlib`, `seaborn` — гистограммы, scatter-графики, boxplot'ы, тепловые карты корреляций, визуализация кластеров

**Предобработка (`sklearn.preprocessing`)**
- `LabelEncoder` — кодирование бинарных/категориальных признаков
- `StandardScaler` — нормализация числовых признаков
- ручной маппинг порядковых категорий (возраст, дозировки препаратов)
- `pandas.get_dummies` — one-hot encoding

**Классификация (`sklearn`)**
- `KNeighborsClassifier`
- `LogisticRegression`
- `DecisionTreeClassifier`
- `train_test_split`, `classification_report`, `confusion_matrix`, `accuracy_score`

**Кластеризация и понижение размерности (только HW7)**
- `KMeans`, `DBSCAN`, `GaussianMixture`
- `PCA` — визуализация в 2D
- `NearestNeighbors` — подбор параметра `eps` для DBSCAN
- метрики: `silhouette_score`, `adjusted_rand_score`, `normalized_mutual_info_score`, `homogeneity_completeness_v_measure`

**Общие ML-навыки, отработанные в проекте**
- разведочный анализ данных (EDA) и выявление выбросов
- работа с пропущенными и категориальными данными
- подбор гиперпараметров (k для KNN и KMeans, число компонент для GMM, eps для DBSCAN)
- сравнение моделей по качеству и времени обучения
- анализ дисбаланса классов
- оценка кластеризации без учителя относительно истинных меток
